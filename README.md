# الحديد — دليل النشر

هاد المشروع جاهز بالكامل، وباقي بس ٤ مراحل: Supabase (قاعدة البيانات) → GitHub (رفع الكود) → Vercel (النشر) → تثبيت على الموبايل.

---

## المرحلة ١: إنشاء مشروع Supabase (٥ دقايق)

1. روح لـ **supabase.com** واعمل حساب مجاني (بالإيميل أو GitHub).
2. دوس **New Project**. اختار أي اسم، وكلمة سر لقاعدة البيانات (احفظها بمكان آمن، بس ما رح تحتاجها بعدين بشكل مباشر)، واختار أقرب Region إلك.
3. استنى دقيقة لين يخلص التجهيز.
4. من القائمة الجانبية، روح لـ **SQL Editor** → **New query**.
5. افتح ملف `supabase-schema.sql` من هاد المشروع، انسخ كل محتواه، ولزقه بمحرر SQL، ودوس **Run**.
   - هاد بينشئلك الجدول ويفعّل الحماية (RLS) تلقائيًا.
6. **مهم جدًا:** روح لـ **Authentication** → **Providers** → **Email**، ووقف خيار **Confirm email**. (السبب موضّح بآخر ملف SQL — التطبيق بيستخدم إيميلات داخلية وهمية، فتأكيد الإيميل ما رح يوصل أبدًا).
7. روح لـ **Project Settings** → **API**. رح تلاقي هناك:
   - **Project URL**
   - **anon public key**
   احفظهم، رح تحتاجهم بالمرحلة الجاية.

---

## المرحلة ٢: رفع الكود على GitHub

1. لو ما عندك حساب GitHub، اعمل واحد مجاني على **github.com**.
2. اعمل **repository** جديد (خاص Private أو عام Public، بحرية).
3. حمّل كل ملفات هاد المشروع (اللي رح تشوفها بالأسفل) لجهازك، وارفعها للـ repository (إما بالسحب والإفلات من واجهة GitHub مباشرة، أو عبر git من جهازك).

**ملاحظة:** ملف `.env` (لو سويته محليًا) ما لازم يترفع أبدًا — موجود أصلاً بـ `.gitignore` عشان ما ينرفع بالغلط.

---

## المرحلة ٣: النشر على Vercel

1. روح لـ **vercel.com** واعمل حساب (الأسهل: سجل دخول بحساب GitHub تبعك مباشرة).
2. دوس **Add New** → **Project**، واختار الـ repository اللي رفعته.
3. Vercel رح يتعرف على المشروع كـ Vite تلقائيًا. بس قبل ما تدوس Deploy:
4. روح لقسم **Environment Variables** وضيف:
   - `VITE_SUPABASE_URL` = الرابط اللي حفظته من Supabase
   - `VITE_SUPABASE_ANON_KEY` = المفتاح اللي حفظته من Supabase
5. دوس **Deploy**. استنى دقيقة أو دقيقتين.
6. بعد ما يخلص، رح ياخذك Vercel لرابط دائم شكله شي متل:
   `https://gym-app-al-hadid.vercel.app`

هاد الرابط ثابت، وأي تحديث تعمله للكود وترفعه على GitHub، Vercel بينشره تلقائيًا بنفس الرابط.

---

## المرحلة ٤: تثبيت التطبيق على الموبايل

### آيفون (Safari)
1. افتح الرابط بمتصفح **Safari** (لازم Safari تحديدًا، مو كروم).
2. دوس زر المشاركة (المربع مع السهم لفوق).
3. مرّر لتحت ودوس **إضافة إلى الشاشة الرئيسية** (Add to Home Screen).
4. دوس **إضافة**. رح تطلعلك أيقونة "الحديد" على شاشتك الرئيسية، وتفتح بدون شريط متصفح — متل تطبيق عادي.

### أندرويد (Chrome)
1. افتح الرابط بمتصفح **Chrome**.
2. دوس القائمة (٣ نقاط فوق يمين).
3. دوس **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
4. أكّد. رح تطلعلك الأيقونة زي أي تطبيق مثبّت عادي.

**أي حدا تاني** بس ياخذ نفس الرابط ويسوي نفس الخطوات، وبينشئ حسابه الخاص فيه (اسم مستخدم وكلمة سر) — بيانات كل شخص منفصلة تمامًا عن التانية بفضل حماية RLS.

## هيكلية المشروع

```
gym-pwa/
├── index.html              نقطة الدخول HTML + إعدادات iOS/Android
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
├── .env.example             انسخه لـ .env محليًا وعبّي القيم (لو بدك تجرب محليًا)
├── supabase-schema.sql       شغّله مرة وحدة بلوحة Supabase
├── public/
│   ├── manifest.webmanifest  تعريف التطبيق كـ PWA
│   ├── sw.js                  service worker بسيط بدون كاش
│   └── icons/                 أيقونات التطبيق (192 و512)
└── src/
    ├── main.jsx                نقطة الدخول لـ React
    ├── App.jsx                 كل منطق وواجهة التطبيق (نفسه القديم + Supabase بدل window.storage)
    ├── supabaseClient.js        اتصال Supabase
    └── index.css                Tailwind
```

## تجربة محلية قبل النشر (اختياري)

لو حابب تجرب عندك بالجهاز قبل ما تنشر:

```bash
npm install
cp .env.example .env   # وبعدين عبّي القيم الحقيقية جوا .env
npm run dev
```

رح يفتحلك رابط محلي (localhost) تقدر تجرب عليه من متصفح جهازك.
